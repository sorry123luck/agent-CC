# Security Policy

Please do not report private screenshots, chat logs, API keys, or local runtime databases in public issues.

## Sensitive Data

OpenClaw may process desktop screenshots and OCR text during local development. Treat generated artifacts as sensitive by default.

## Reporting

For public issues, provide:

- the failing command or API endpoint;
- sanitized logs;
- synthetic screenshots or diagrams when possible;
- expected and actual behavior.

Do not include real personal messages, secrets, or private window captures.
